⚠️ Microfono non disponibile
Stai aprendo il file direttamente dal computer (file://).
Il browser blocca il microfono in questa modalità.

Soluzione rapida — segui questi passi:

1. Premi il tasto ⊞ Win e cerca PowerShell → aprilo
2. Scrivi questo comando e premi Invio:
python -m http.server 8080
3. Apri Chrome e vai su:
http://localhost:8080/music_trainer.html
4. Il microfono funzionerà ✅

⚡ Soluzione definitiva: carica il file su GitHub Pages come il rapportino di cantiere — funzionerà sempre, da ovunque, senza installare nulla.
